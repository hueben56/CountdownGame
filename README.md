# CountdownGame
The game Countdown gives the player 6 numbers and a target number. They must use the 6 numbers and standard mathematical operators ( + - * / ) to reach the target. Can only use the numbers once, but all may not be needed. 

## Fullscreen on Fire tablet (Silk)
The game ships with a web app manifest. After merging/updating, remove the old home screen shortcut and re-add it via the Silk menu > "Add to Home screen" (or "Install app") so the manifest is picked up and the game launches fullscreen. A "Full Screen" button at the bottom of the page toggles fullscreen when running in the browser.
